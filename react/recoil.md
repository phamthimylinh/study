# 1. Recoil là gì?
- Là một thư viện quản lý state cho react được phát triển bởi facebook
- Nó được thiết kế để cung cấp cách quản lý global state đơn giản, hiệu quả, và tích hợp chặt chẽ với react
- Cho phép các component truy cập + update state linh hoạt mà không cần truyền qua nhiều tầng prop hoặc sử dụng các thư viện phức tạp như redux
